# Internal Documentation

This directory contains internal documentation for building and running the site locally.
These files are **excluded** from the Jekyll build and will not be served as part of the public site.

## Build and Run Locally

1.  **Dependencies**: Ensure you have Ruby and Bundler installed.
2.  **Install**: Run `bundle install`.
3.  **Serve**: Run `bundle exec jekyll serve` to start the local development server.
4.  **View**: Open `http://localhost:4000` in your browser.
